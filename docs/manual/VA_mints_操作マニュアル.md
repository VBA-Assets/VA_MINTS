# 第1章 ツールの概要

## 1.1 これは何をするツールか

**VA mints**は、民事裁判書類電子提出システム「mints」の「記録」への提出前に、フォルダ単位でファイル群の内容を確認し、mintsの制約（用紙サイズ・ファイル名・パスワードの有無・証拠番号標記等）に適合しているかを一括してチェックするためのツールです。

Ver.300から、mintsに提出するPDFの準備（ページの編集・ファイルの結合と分割・ファイル名・証拠番号・用紙の大きさ・圧縮など）を、このツールだけで済ませられるようにしました。ただし、ファイル形式の変換（Word等からPDFへの変換）とOCRの付与は行いません。これらが必要な場合は、普段お使いのアプリケーションで処理していただき、処理後のファイルを本ツールに再度読み込んで再検証してください。

これは機能不足ではなく意図的な設計です。証拠として提出する文書は、内容の変更それ自体が証拠価値の評価に影響しかねません。「技術的に情報を失わない処理だから自動実行してよい」という判断は、本ツールでは採用していません。ファイルの中身を変える処理（証拠番号スタンプ、ファイル名整形、メタデータ除去、枝番ファイルの結合、用紙をA4にそろえる処理、ページの回転など）は、ファイルごとに、行う処理をチェックボックスで選び、プレビューで結果を確かめられるようになっています。実際にファイルを更新するのは、「ファイルを更新」を押し、処理ごとの件数を示した確認に「OK」と答えたときだけです。更新する前のファイルは、同じフォルダの中の「元のファイル」フォルダに残り、「元のファイルに戻す」でいつでも元に戻せます。

## 1.2 できること・できないこと

**できること（検出・警告）**

- フォルダ内の全ファイルのスキャンと状態把握（形式・サイズ・分類）
- ファイル名の制約の検出（100文字超過・禁止文字・JIS X 0213外の文字の可能性）
- 単体ファイルの200MB超過検出（合計サイズとは別の重大警告）
- パスワード付きPDFの検出
- 操作制限（印刷・コピー制限）PDFの検出
- 用紙サイズ（A4／A3以外）・向きの不一致検出
- 墨消し完全性の検証（黒塗り・マーカー下の文字情報の残存検出。スキャンして文字の読み取り〔OCR〕をかけた後に、画像の上で黒く塗った所に残る、見えない文字の検出を含む）
- 号証の連番・欠番チェック
- 個人情報らしきパターン（マイナンバー・電話番号・メールアドレス・住所・銀行口座・クレジットカード番号等）の検出

**できること（チェックボックスで選び、確認のうえで実行する処理）**

- ファイル名整形（100文字以内への調整、禁止文字の除去）
- メタデータ除去（作成者情報、Exif位置情報、MP3のタグ等。動画〔MP4〕のタグは、見つけてお知らせするだけです）
- 200MB単位の仕分け（複数回提出のための事前仕分け。「提出用_01」等のサブフォルダを自動で作り、ファイルを移します）
- 更新したファイルを、更新する前の状態に戻す（「元のファイルに戻す」）
- 証拠番号（甲001等）の右上スタンプ（**スタンプする番号は、ファイル名の先頭に付けられた証拠番号からそのまま決まります**〔詳細は3.2節参照〕。位置調整可能）
- 枝番ファイルの結合
- ページの編集（削除・挿入・並べ替え・回転）、ファイルの結合・分割、1つのファイルの中の枝番の区切り（3.4節）
- ファイル名の変更（3.2節）
- 圧縮（画質を損なわない圧縮と、画像を軽くする圧縮。3.3節）
- 用紙をA4にそろえる（A4・A3以外の大きさのページを、A4の用紙に載せる。3.3節）
- 付箋・コメント・添付ファイルを取り除く（3.3節）
- 証拠説明書のPDFを作る（号証と標目は、ファイル名から決まります。入力に合わせてその場で作り直し、一覧で見た目を確かめられます。3.8節）

**できないこと（意図的に実装していない機能）**

- ファイル形式の変換（DOCX/XLSX/PPTX→PDF、TIFF等→JPEG/PNG、動画・音声形式の変換）
- OCRによるテキストレイヤーの付与・削除
- 墨消し漏れの自動修復（検出・警告のみ）
- 無彩色画像のグレースケール変換（白黒・グレー化）
- 動画・音声の圧縮
- 動画（MP4）のタグ（撮影した場所・機種など）の除去（見つけて、右のペインでお知らせするだけです）

これらが必要な場合は、他の専用ソフトで対処したうえで、本ツールに再度読み込んで再検証してください。

## 1.3 安全性に関する設計方針

- **完全ローカル動作**：いかなる処理段階でも外部ネットワーク通信を行いません。クラウドAPI・外部OCRサービス・外部変換サービス・利用状況の送信・自動アップデート確認、いずれも実装していません。証拠・準備書面等の内容が、お使いのパソコンの外部に送信されることはありません。
- **生成AI（LLM等）を使用しない**：検出処理はすべて正規表現やライブラリによる機械的な判定であり、生成AIによる文字起こしや要約は行いません。
- **更新する前のファイルを必ず残す**：Ver.200から、対象フォルダの中のファイルを、その場で更新する方式になりました。更新する前のファイルは、同じフォルダの中に作られる「元のファイル」フォルダに残ります。「元のファイルに戻す」で、更新する前の状態（名前・位置・内容）に戻せます。更新は、確認の画面で「OK」と答えたときにだけ行われます。

# 第2章 導入方法

## 2.1 配布物の構成

本ツールは、次のファイル一式で構成されています。

| ファイル | 内容 |
|---|---|
| `VA_mints.exe` | 実行ファイル本体（Python環境不要） |
| `config.yaml` | 数値パラメータ等の設定ファイル（テキストエディタで編集可能） |
| `LICENSE` | ライセンス条文（MIT License） |
| `THIRD_PARTY_NOTICES.txt` | VA mints が使っている部品（PDF・画像を扱うライブラリ、アイコンなど）のライセンスの表示 |
| マニュアル（フォルダ） | 本マニュアル（PDF） |
| `source/` | ソースコード一式（Python。改変・再配布はライセンス条件の範囲内で自由） |

## 2.2 起動方法

1. `VA_mints.exe` と `config.yaml` を、**同じフォルダ内**に置いてください（config.yamlは実行ファイルに内蔵されておらず、外部ファイルとして読み込む仕組みのため、必ず同じフォルダに置く必要があります）。
2. `VA_mints.exe` をダブルクリックして起動します。Python環境のインストールは不要です。
3. Windows Defender SmartScreen等により警告が表示される場合がありますが、これは未署名の実行ファイルに一般的に表示されるものです。内容にご不安がある場合は、`source/` フォルダ内のソースコードをご確認いただくか、ご自身の環境でビルドし直してご利用ください。

## 2.3 動作環境

Windows環境を想定しています（法律事務所の一般的なPC環境に合わせています）。

Macでは、ソースコード（`source/` フォルダ。GitHubのVBA-Assets/VA_MINTSでも公開しています）から、Python 3で動かすことができます（**動作は保証しません**。Mac用の実行ファイルは配布していません）。手順は次のとおりです（ターミナルで `source/` フォルダに移動してから実行します）。

1. `python3 -m pip install -r requirements.txt`
2. `python3 main.py`

Macで動かす場合、Windowsと次の点が異なります。

- 画像（JPEG・PNG）に焼き込む証拠番号の書体は、Mac標準のヒラギノ角ゴシックになります（Windowsではメイリオ）。字の形だけが異なります。PDFに焼き込む証拠番号はWindowsと同じです。
- 完了ダイアログの「フォルダを開く」は、Finderで更新したフォルダを開きます。
- Macのファイル名は、濁点・半濁点を分けた形で保存されていることがあります。文字数・JIS X 0213外の文字の判定は、濁点・半濁点を合わせた形で行います。

# 第3章 基本的な使い方

## 3.1 画面の構成と、ファイルの読み込み

画面上部の操作は、Wordなどと同じ**リボン**の形にまとまっています。ボタンは「読み込み」「更新」「ページ」「証拠説明書」の組に分かれ、組の名前が下に小さく表示されます。各ボタンや欄にマウスを重ねると、少し間をおいて説明書きが表示されます。

リボンの3つのボタン（「ファイルを読み込み」「ファイルを更新」「元のファイルに戻す」）と同じ操作は、画面上部の**［ファイル］メニュー**からも行えます（押せる・押せないは、リボンのボタンと同じです）。［ファイル］メニューの**［オプション］**では、証拠番号スタンプの文字の大きさと見た目（黒字・赤字・赤字に赤枠）を変えられます（3.3参照）。ウィンドウの大きさ・位置と、最大化していたかは、閉じるときに覚え、次に起動したときに同じにします（パソコンのユーザーごとに保存されます）。

リボンの下は、**3つのペイン（区画）**に分かれています。ペインの境目は、左右にドラッグして幅を変えられます。

| ペイン | 表示されるもの |
|---|---|
| 左 | 読み込んだファイルの名前と大きさの一覧。一覧の下に、大きさの合計（圧縮にチェックがあるときは、圧縮の後の見込みも）が出ます。mints に1回で送れるのは合計200MBまでなので、合計と比べて、分けて送るか、圧縮するかの目安にしてください |
| 中央 | 左で選んだファイルのプレビュー（右端のスクロールバーでページを送ります） |
| 右 | 処理の項目（チェックボックス）。左で選んだファイルに適用するものにチェックが付きます |

起動後、まず「読み込み」の組で**対象フォルダ**（mintsに提出するファイルを集めたフォルダ）を選択します。フォルダ欄にパスを貼り付けるか（エクスプローラーの［パスのコピー］で写したものも、そのまま貼り付けられます）、フォルダ欄の右にある「...」ボタンから参照ダイアログで選びます。フォルダ欄は、長いパスも見えるよう、［ファイルを読み込み］ボタンと同じ高さにしてあります（長いパスは折り返して表示されます）。Ver.200から、出力フォルダはありません（対象フォルダの中のファイルを、その場で更新します）。**更新した後の対象フォルダのファイルが、そのまま mints に提出するファイルです**（別の場所に提出用のファイルができるのではありません。合計が200MBを超えるときは、対象フォルダの中の「提出用_01」等に分かれます。3.6参照）。Ver.300で、この欄の名前を「入力フォルダ」から「対象フォルダ」に改めました。

読み込むのは、対象フォルダの直下のファイルと、「提出用_01」等のフォルダ（3.6参照）の中のファイルです。そのほかのサブフォルダの中は読み込みません（「元のファイル」フォルダ〔3.5参照〕の中も読み込みません）。一度に提出するファイルは、1つのフォルダの直下に集めてください。Ver.300で「サブフォルダ内のファイルも含める」のチェックボックスを外しました（mintsにはファイルを1つずつ送るので、フォルダの分けはmintsに伝わりません。また、合計が200MBを超えて「提出用_NN」に分けるときは、どのサブフォルダのファイルもまとめて移すことになり、分けが崩れるためです）。

「ファイルを読み込み」を押すと、対象フォルダ内の全ファイルが自動的にスキャンされ、左のペインに一覧表示されます。読み込みではファイルは変更されません。OSやアプリケーションが自動生成する一時ファイル（Thumbs.db、desktop.ini、Officeの作業ファイル〔~$で始まるもの〕、.tmpファイル）は、提出対象になり得ないため読み込み対象から自動的に除外されます。

左のペインの一覧には、ファイル名だけが表示されます。行は、検出の結果に応じて色分けされます。

| 行の色 | 意味 |
|---|---|
| 薄い緑 | 適合済み（検出できる要対処事項がない） |
| 薄いオレンジ | 要修正（ファイル名・メタデータ・パスワード・用紙寸法など、何かが検出された） |
| 薄い青 | 要変換（Wordなど、mints「記録」の対応形式ではない。PDF等に変換してから読み込み直す） |
| 灰色 | 対象外（未対応の形式、拡張子と中身の不一致など） |

**号証の連番・欠番・重複の疑い**（甲002が欠けている等）があるときは、一覧の下に赤字で表示されます（複数のファイルにまたがる検出結果のため、ここにまとめて表示します）。

**「ファイルを更新」のボタンは、ファイルを読み込むまでは押せません**（灰色の表示になっています）。読み込みが済むと押せるようになります。

## 3.2 ファイル名と証拠番号の扱い

**ファイル名は、左のペインで変えられます**（Ver.300から）。

- 名前をダブルクリックするか、ファイルを選んで F2 キーを押す（又は、右クリックのメニュー・メニューの［編集］の［名前を変更］）と、名前を入れる欄が出ます。拡張子の前の部分が選ばれた状態になります。
- 名前を直して Enter キーで決めます。Esc キーでやめます。
- 使えない文字（`\ / : * ? " < > |`）がある、100文字を超える、拡張子を変えた、同じフォルダに同じ名前のファイルがある、のどれかのときは、欄の近くに赤字で理由が出て、決められません。mintsで使えないかもしれない文字（JIS X 0213外の文字の疑い）は、赤字で知らせますが、決めることはできます。
- 名前を変えたファイルは、左の一覧に新しい名前が「＊」付きで出ます。**実際のファイルの名前が変わるのは、［ファイルを更新］を押したときです**（確認の画面に「ファイル名の変更：○件」と出ます）。元に戻す（Ctrl+Z）・やり直す（Ctrl+Y）もできます。
- 名前だけを変えて、ほかの処理をしないファイルは、中身は変わらないので「元のファイル」フォルダには写さず、元の名前を記録しておきます。［元のファイルに戻す］で元の名前に戻ります。
- 名前を変えると、新しい名前の先頭の証拠番号で、証拠番号スタンプの項目が出直します（たとえば「契約書.pdf」を「甲004 契約書.pdf」にすると、「甲004」のスタンプの項目が出ます）。名前を変えたファイルには、ファイル名整形の項目は出ません。
- 枝番ファイル結合のチェックが入っているファイルは、名前を変えられません（結合しない場合は、チェックを外してから変えてください）。
- 証拠番号を付ける・直すときも、この名前の変更で行います（証拠番号の書き方は下記）。

読み込んだファイル名の**先頭**が証拠番号の形式に合致すると、そのファイルは証拠番号処理（右上スタンプ・枝番結合等）の対象候補として扱われ、右のペインの処理の項目に「証拠番号スタンプ」「枝番ファイル結合」が表示されます。証拠番号の形式に合致しない場合（準備書面・証拠説明書等と推定される場合）は、証拠番号処理は適用されません。証拠番号の書き方は次のとおりです。

- **ファイル名の一番先頭に置いてください。** 途中や末尾にある場合は認識されません（`20260726 甲001 売買契約書.pdf`や`売買契約書 甲001.pdf`は認識されません）。
- **符号＋半角3桁の数字**が基本形です（符号は甲・乙・丙。例：`甲001`）。数字は3桁ちょうどが必要で、桁数が異なる書き方（`甲1`等）は認識されません。
- **被告が複数などで添字が必要な場合**は、符号の直後に半角英字を1文字加えます（例：`乙A001`）。
- **枝番のある複数ファイルを1つに結合したい場合**は、証拠番号の後ろに「-」（半角ハイフン）又は「_」（アンダースコア）で区切って枝番の数字を続けます（例：`甲001-1`、`甲001_1`）。結合対象になるのは、同じ証拠番号で枝番だけが異なる2件以上のファイルです。
- 既に1ファイルへまとめてあり、範囲（例：1〜20号証）をファイル名に表記したい場合は、枝番の後ろに「~」（半角チルダ）で区切って終端の枝番を続けます（例：`甲001-1~20`）。この表記のファイルは既に結合済みとみなされ、結合候補には含まれません。
- 証拠番号（枝番を含む）より後ろの部分は「標目」として自由に付けられます。一次資料の例（「甲001 売買契約書原本」）に合わせ、証拠番号との間に半角スペースを1つ入れる書き方を推奨します。

証拠番号スタンプに実際に使われる番号は、この先頭部分（符号・添字・数字・枝番）から自動的に決まります。枝番ファイルを結合する場合、結合後のファイル名も、代表となるファイル（最小の枝番）の証拠番号・区切り文字・標目をそのまま踏襲して自動生成されます（例：`甲001-1 領収書A.pdf`と`甲001-2 領収書B.pdf`を結合すると`甲001-1~2 領収書A.pdf`になります）。

なお、ファイル名がmintsの制約に技術的に反する場合（100文字超過・禁止文字）の整形は、右のペインの処理の項目（3.3参照）で選べます。名前を自分で直すこともできます（上記）。号証の連番・欠番・重複はチェック機能が検出・警告しますので、必要な改名は左のペインで行ってください（自動での番号の付け直しはしません）。

## 3.3 処理の項目とプレビュー

右のペインには、**処理の項目**（ファイル名整形・メタデータ除去・付箋・コメント・添付ファイルの除去・用紙をA4にそろえる・証拠番号スタンプ・枝番ファイル結合・画像を軽くする・画質を損なわない圧縮）が、いつも同じ並びで表示されています。左のペインでファイルを選ぶと、中央のペインにそのファイルのプレビューが表示され、右のペインでは、**そのファイルに適用する項目にチェックが付きます**。そのファイルに当てはまらない項目（メタデータのないファイルの「メタデータ除去」など）は、灰色の表示になり、チェックできません。

**右のペイン（処理の項目）**

- **本ツールでは対処できない検出結果**（パスワード・操作制限・墨消し残存の疑い・個人情報らしきパターン）は、検出されたときに、**処理の項目の上に赤字で表示**されます。これらは他のアプリで対処のうえ、本ツールに再度読み込んで再検証してください。単体で200MBを超えるファイルも赤字で表示されますが、これは本ツールの「画像を軽くする」又はファイルの分割で対処できます（3.6節）。
- **本ツールで実行できる処理**の項目のうち、そのファイルに当てはまるものには、処理の内容（整形後のファイル名、検出されたメタデータの項目、スタンプする番号など）が書かれます。**必要と判断された項目には、読み込んだときにチェックが自動で付いています。** チェックは個別に付け外しできます。チェックを外した処理は行われません。
- 自動でチェックが付くのは、ファイル名整形（100文字超過・禁止文字があるとき）、メタデータ除去（メタデータが検出されたとき）、用紙をA4にそろえる（A4・A3以外の大きさのページがあるとき）、PDFの証拠番号スタンプ、枝番ファイル結合です。**画像（JPEG・PNG）の証拠番号スタンプは、チェックできる状態になりますが、自動ではチェックが付きません**（写真などは見た目そのものが証拠の内容になり得ること、文書がどちらを向いているかはツールには判別できないことから、個別にご判断いただくためです）。
- **付箋・コメント・添付ファイルを取り除く**（PDF）：付箋のコメント、ハイライトなどに書き込んだコメントの文と作成者名、PDFに埋め込んだ添付ファイル、JavaScript（スクリプト）が見つかったPDFに表示されます（項目に、見つかった数が書かれます）。事務所の中で付けたコメントや作成者名が、気づかれないまま提出されるのを防ぐためのものです。**取り除くのは、見えていない中身だけです。** ハイライト・下線・図形・スタンプ・手書き・テキストボックスなどの見た目は残し、その中のコメントの文と作成者名だけを外します（付箋と添付ファイルのアイコンは消えます）。リンクとフォームの欄（入力した値）は残します。原本を作った人が付けたコメントが証拠の内容である場合もあるので、**自動ではチェックが付きません。** チェックを入れないまま更新するときは、確認の画面に「付箋・コメント・添付ファイルが残るファイル：○件」と表示されます。
- **用紙をA4にそろえる**（PDF）：mintsは、A4・A3以外の大きさのページを含むPDFを受け付けません（レターサイズのように、見た目がA4に近いものも同じです）。この項目は、A4・A3以外の大きさのページ（何ページ目かが書かれます）を、同じ向きのA4の用紙に載せます。**大きいページは縮めて収め、小さいページは原寸のまま、用紙の真ん中に置きます**（小さいものを引き伸ばすことはしません）。ページは画像にしないので、文字・画像・テキストは変わりません。A4・A3のページには触れません。mintsに出すために要る処理なので、**自動でチェックが付きます。** チェックを入れるとプレビューがそろえた後の姿に切り替わるので、縮めた字が読めることを確かめてください（横長のページはA4の横置きになり、「向きが基本形と不一致」の注意が出ます。mintsは横置きのA4も受け付けます。内容が縦向きのときは、そのページを選んで、リボンの［回転］から［左に90°回転］か［右に90°回転］を選んで回してください）。証拠番号スタンプは、そろえた後の用紙の右上に押します。そろえたファイルのページを編集し直したときなど、元のファイルから作り直すときも、もう一度そろえます。
- **向きの注意**：A4の横向き・A3の縦向きのページがあるPDFでは、処理の項目の上に「向き：…のページがあります（○ページ目）」と表示されます。mintsは縦向き・横向きのどちらのPDFも受け付けますが（操作マニュアル別紙4）、内容の向きと用紙の向きが違うと、mintsがページの上の辺に付けるタイムスタンプが文字に重なります。内容の向きが違うページ（横向きの用紙に縦書きの文書が横倒しで載っているなど）は、［そのページを選ぶ］を押し、リボンの［回転］から［左に90°回転］か［右に90°回転］を選んで回してください（3.4節）。表やグラフなど、用紙の向きどおりの内容なら、そのままで構いません。回したページの注意は消えます。Ver.300で、右のペインの「向き補正」の項目はなくし、ページの回転にまとめました。
- **証拠番号スタンプ**：PDFの**1ページ目の右上だけ**に押します（2ページ目以降には押しません。1つのファイルの中で枝番の区切りを付けたときは、区切りごとの最初のページに押します。3.4節）。文字の大きさは、既定で**16ポイント**（字の高さ約5.6mm。紙の「甲第　号証」のゴム印の字とほぼ同じ大きさ）です。［ファイル］→［オプション］で、8〜36ポイントの間で変えられます。見た目は、既定で**赤字**です。［ファイル］→［オプション］で、黒字・赤字・赤字に赤枠から選べます。変えた大きさと見た目は、パソコンのユーザーごとに保存され、次に起動したときも使われます（［既定に戻す］で16ポイント・赤字に戻ります）。すでにスタンプを付けたファイルの大きさ・見た目は変わりません。チェックがあると、項目の下の上下左右ボタンで焼き込み位置を微調整できます（動かした位置は、そのファイルだけに使われます。スタンプは、ページを回した後の右上に載ります）。
- **枝番ファイル結合**：同じ証拠番号で枝番だけが異なるPDFが2件以上あるとき、そのどのファイルを選んでも、同じ1つのチェックが表示されます（結合するすべてのファイルで共通です）。チェックがある間は、結合後のファイルについての項目（枝番ラベルのスタンプ等）が表示されます。チェックを外すと結合は行われず、そのファイルだけの項目に切り替わります。
- **画像を軽くする**（PDF・JPEG・PNG）：画像の解像度を下げて、ファイルを小さくします。解像度は、項目の下で選べます（300dpi・200dpi・150dpi。既定は300dpiで、細かい字もほとんど損なわずに、600dpiのスキャンやスマートフォンの写真を小さくできます。小さくならないときは200dpi・150dpiを選ぶと、さらに小さくなりますが、粗くなります。mintsに解像度の決まりはなく、字が読めることが求められます）。解像度は、A4の紙に置いたときの細かさで数えます。もともと選んだ解像度より粗い画像は、そのままです。PDFの中の画像はJPEGにし、JPEGのファイルはJPEGのまま、PNGのファイルはPNGのまま（画質を損なわない形で）保存し直します。写真の向き（撮影時の向きの情報）は画像に反映し、撮影日時などの情報は残します（取り除くのは、メタデータ除去の項目です）。白黒（1ビット）・CMYK・透明の部分のある画像など、色や形が変わるおそれのある画像には触れません。**細かい字や写真が粗くなることがあるので、自動ではチェックが付きません。** チェックを入れると、プレビューが軽くした後の姿に切り替わるので、字が読めることを確かめてください。
- **画質を損なわない圧縮**（PDF）：PDFの中の使っていないデータを除き、データを詰め直して小さくします。見た目・文字・画像は変わりません（小さくならないときは、何もしません）。**大きなPDF（既定で10MB以上。設定ファイルの `compress` で変えられます）には、自動でチェックが付きます。** スキャンしたPDF（中身がJPEGの画像）は、ほとんど小さくならないことがあります。その場合は「画像を軽くする」を試してください。
- 2つの圧縮の項目は、右のペインの「ファイルを小さくする」の枠にまとめてあります。どちらかにチェックがあると、枠の下の区切り線の下に**大きさの見込み**（例：「上で選んだ圧縮の後の大きさ：12.2MB→約0.7MB」）が出ます。チェックや解像度を変えると、見込みも計算し直します。どこまで小さくすればよいかは、左の一覧の下の合計と、その右の「mintsに1回で送れるのは合計200MBまでです。」を比べてください（mints の大きさの決まりは、これだけです。合計が200MBを超えても、「提出用_NN」に分けて、何回かに分けて送れます。1つで200MBを超えるファイルだけは、小さくするか分割しないと送れません）。見込みは、そのファイルに、選んだ圧縮だけを行った場合のものです（裏で計算するので、大きなファイルでは少し時間がかかります）。見込みが出ているファイルは、200MBの仕分け（3.6節）も、圧縮の後の大きさで行います。
- **圧縮したファイルは、読み込み直したときも、圧縮の項目にチェックの入った状態で表示されます**（証拠番号スタンプと同じく、チェックは「済んでいる」ことを表します）。チェックを入れたままなら、もう一度更新しても何も起きません（二重に圧縮することはありません）。
- **チェックを外して（「画像を軽くする」は解像度を選び直して）「ファイルを更新」を押すと、「元のファイル」フォルダの更新前のファイルから作り直します。** 画像は元の解像度に戻ります（解像度を選び直したときは、元の画像からその解像度で作り直します。粗くした画像を広げることはしません）。スタンプなど、ほかの済んだ処理は、チェックのとおりにやり直します。**更新の後に他のアプリでそのファイルを直していた場合、その内容は失われます**（確認の画面に「圧縮をやめる・解像度を変える：○件」と表示されます）。
- 圧縮したファイルのページを編集し直したときも、元のファイルから作り直し、チェックの入っている圧縮をやり直します。
- 要変換・対象外のファイル（行の色が薄い青・灰色）は、処理の項目がすべて灰色になり、何をすればよいかの案内が赤字で表示されます。これらのファイルは更新されません。

**中央のペイン（プレビュー）**

- プレビューは、**右のペインでチェックの付いている処理を行った後の状態**を表示します。チェックを付け外しすると、プレビューもその場で描き直されます（証拠番号スタンプ・用紙をA4にそろえる・付箋・コメント・添付ファイルを取り除く・画像を軽くする）。
- 複数ページのPDFは、プレビューの右端の**スクロールバー**（又はマウスのホイール）でページを送って、全ページを確認できます（1ページずつ表示されます。右下に、いま何ページ目かが表示されます）。**原本に証拠番号が既に記載されていないか（重複スタンプの防止）は、1ページ目だけでなく全ページを確認したうえで判断してください。** 結合するファイルは、左のペインで1つずつ選んで確認してください（スタンプは、結合するそれぞれのファイルの1ページ目に、その枝番で載ります）。
- 画像（JPEG・PNG）は、小さいものも、プレビューの枠いっぱいの大きさに拡大して表示されます（表示だけで、ファイルは変わりません）。
- パスワード付きファイル、音声・動画ファイルなど、プレビューを表示できないファイルには、その旨が表示されます。

## 3.4 ページの編集（削除・挿入・並べ替え・回転）とファイルの結合・分割

ページの編集ができるのは、PDF（パスワードのないもの）です。中央のペインの左には、ページの縮小画像が縦に並びます。

- **見る**：縮小画像をクリックすると、そのページが右の大きなプレビューに出ます。
- **選ぶ**：Ctrl を押しながらクリックすると、ページを1つずつ選びに足したり外したりできます。Shift を押しながらクリックすると、間のページをまとめて選べます。
- **並べ替える**：縮小画像をドラッグし、青い横線の位置で放すと、そこへ動きます（選んだページをまとめて動かせます）。
- **削除する**：ページを選び、Delete キー、リボンの「ページ」の組の［ページを削除］、又は右クリックのメニューで消します。すべてのページを消すことはできません。
- **挿入する**：ページを選び、［ページを挿入］を押して、入れるファイル（PDF・JPEG・PNG）を選ぶと、そのファイルの全ページが、選んだページの後ろに入ります。対象フォルダの中のファイルも、フォルダの外のファイルも選べます。入れた元のファイルは、そのまま残ります（動かしたり消したりしません）。画像は、A4（画像の縦横に合わせて縦置き又は横置き）の1ページにして入れます。JPEG は再圧縮せずにそのまま埋め込むので、画質は変わりません。写真に付いている撮影日時・撮影場所（GPS）などの情報（EXIF）は、取り除いて入れます。
- **回転する**：ページを選び、リボンの［回転］を押して、［左に90°回転］［右に90°回転］［180°回転］から選んで回します（縮小画像の右クリックのメニューからも選べます）。逆さまにスキャンしたページなども直せます。回すのはPDFの回転の情報だけで、ページの中身・画質・文字は変わりません。
- **元に戻す・やり直す**：［元に戻す］（Ctrl+Z）・［やり直す］（Ctrl+Y）で、ページの編集を何度でも取り消し・やり直しできます。

同じ操作は、メニューの［編集］と、縮小画像の右クリックのメニューにもあります。

**ページの編集は、［ファイルを更新］を押すまで、実際のファイルには書かれません。** 編集したファイルは、左の一覧の名前の先頭に「＊」が付きます。［ファイルを更新］の確認の画面には「ページの編集：○件」と出ます。更新する前のファイルは、ほかの処理と同じく「元のファイル」フォルダに残り、［元のファイルに戻す］で戻せます。

- まだ更新していない編集があるときに、フォルダを読み込み直したり、画面を閉じたりしようとすると、編集が失われることを確かめるメッセージが出ます。
- 更新したファイルのページを、もう一度編集して更新すると、「元のファイル」フォルダの更新前のファイルから作り直します。そのため、証拠番号スタンプは、並べ替えの後の1ページ目に押し直され、二重にはなりません。
- ページは画像にせず、元のPDFのページをそのまま写して並べます。

**1つのファイルの中で枝番を付ける**

領収書の束のように、1つのPDFのまま、甲005-1、甲005-2…と枝番を付けて出すときに使います。

1. 左の一覧で、ファイル名の先頭に、枝番を付けない証拠番号（例：甲005）を付けます（3.2節の名前の変更）。
2. 次の枝番が始まるページを縮小画像で選び、リボンの「ページ」の組の**［枝番の区切り］**（又は右クリックのメニューの［このページから次の枝番にする］）を押します。
3. 区切りのページの縮小画像の上に青い線が引かれ、ページ番号の横に枝番（例：甲005-2）が出ます。ファイル名は「甲005-1~3 領収書.pdf」のように、枝番の範囲の付いた名前に変わります。
4. 区切りを外すときは、そのページを選んで、もう一度［枝番の区切り］を押します（メニューでは［枝番の区切りを外す］と出ます）。

- 証拠番号スタンプは、**区切りごとの最初のページの右上に、その枝番で**押されます（1ページ目には「甲005-1」）。プレビューでも確かめられます。
- ページを並べ替えると、区切りもそのページについて動きます。区切りのページを削除すると、その区切りはなくなります。
- 区切りがある間にファイル名を変えると、名前の証拠番号の後ろの枝番の範囲は、区切りで決まるものに自動で付け直されます（例：「甲006 領収書.pdf」と変えると「甲006-1~3 領収書.pdf」になります）。区切りがある間は、名前から証拠番号を外せません（外すときは、先に区切りを外します）。
- 枝番ファイル結合のチェックが入っているファイルには、区切りを付けられません。

**ファイルを結合する**

左の一覧で、Ctrl 又は Shift を押しながらクリックして、結合するファイル（PDF・JPEG・PNG）を2つ以上選び、右クリックのメニュー（又はメニューの［編集］）の**［ファイルを結合］**を押します。

- 選んだファイルは、**左の一覧の並び順**につながり、先頭の PDF のファイルに1つにまとまります。名前は、先頭の PDF の名前のままです（変えるときは、結合の後で名前を変えます）。
- 結合したファイルは、左の一覧から隠れ、結合先の名前の後ろに「（2件を結合）」のように出ます。右のペインにも、結合するファイルの名前が出ます。
- 結合の後のページは、ほかのファイルと同じく、削除・並べ替え・回転・挿入・枝番の区切りができます。
- ［ファイルを更新］を押すと、結合先のファイルが作り直され、結合したファイルは「元のファイル」フォルダへ移ります（確認の画面に「ファイルの結合：○件」と出ます）。［元のファイルに戻す］で、すべて元の名前・元の位置に戻ります。
- 元に戻す（Ctrl+Z）で、結合を1回で取り消せます。
- 枝番ファイル結合のチェックが入っているファイルは、結合できません（チェックを外してから結合します）。枝番の区切りのあるファイルは、結合先にだけできます。
- 別々の証拠番号のファイル（例：甲005 と 甲006）を結合すると、右のペインに赤字で注意が出ます。mints では、枝番がある場合を除いて、1つの証拠を1つのファイルで出すことになっています（準備の手引29頁）。止めはしませんので、必要に応じて名前の証拠番号と枝番の区切りを直してください。

**ファイルを分割する**

いくつかの証拠をまとめてスキャンした PDF を、証拠ごとのファイルに分けるときなどに使います。

1. 分けたい位置の、後ろ側の最初のページを縮小画像で選びます。
2. リボンの「ページ」の組の**［ファイルを分割］**（又は右クリックのメニューの［このページから別のファイルにする］）を押します。
3. 選んだページから後ろが、新しいファイルになります。新しいファイルは、左の一覧の、分ける前のファイルのすぐ下に「まとめてスキャン_2.pdf（分割で作るファイル）」のように出ます。
4. 名前を、左の一覧でダブルクリック（又は F2 キー）して、証拠番号の付いた名前（例：甲031 領収書.pdf）に変えます。分ける前のファイルの名前も、同じように変えられます。

- 何か所でも分けられます。分けて作るファイルを、さらに分けることもできます。
- 分けて作るファイルも、ほかのファイルと同じく、ページの編集・枝番の区切り・証拠番号スタンプなどができます（スタンプは、名前の先頭の証拠番号で押します）。
- ［ファイルを更新］を押すと、分ける前のファイルが前半のページで作り直され、分けて作るファイルが新しくできます（確認の画面に「ファイルの分割：○件」「分割で新しく作るファイル：○件」と出ます）。分ける前のファイルは「元のファイル」フォルダに残ります。
- ［元のファイルに戻す］を押すと、分けて作ったファイルは消え、分ける前のファイルが元に戻ります。
- 元に戻す（Ctrl+Z）で、分割を1回で取り消せます。
- 枝番ファイル結合のチェックが入っているファイルと、枝番の区切りのあるファイルは、分けられません。分けて作るファイルは、更新するまでは、ほかのファイルと結合できません。

**一覧からのファイルの削除**

- 左の一覧でファイルを選び（Ctrl・Shiftを押しながらクリックすると、いくつも選べます）、Deleteキーを押すか、右クリックの［一覧から削除］を選びます。一覧から消えます。
- ［ファイルを更新］を押すと、削除したファイルは「元のファイル」フォルダへ移ります（確認の画面に「一覧から削除するファイル：○件」と出ます）。完全には消さないので、［元のファイルに戻す］で元の位置に戻せます。
- 結合するファイル、分割したファイル、枝番ファイル結合のチェックが入っているファイルは、削除できません（先に、結合・分割を元に戻すか、チェックを外してください）。

**一覧へのファイルの追加**

- エクスプローラーからファイルを左の一覧へドラッグアンドドロップするか、エクスプローラーでコピー（Ctrl+C）したファイルを、左の一覧で貼り付け（Ctrl+V。右クリックの［貼り付け（ファイルを追加）］）します。一覧の末尾に「（追加するファイル）」として加わります。フォルダをドロップすると、その直下のファイルが加わります。
- 加えたファイルも、ほかのファイルと同じく、プレビュー・処理の項目・名前の変更・ページの編集などができます。
- ［ファイルを更新］を押すと、対象フォルダに写します（確認の画面に「追加するファイル：○件」と出ます）。元の場所のファイルには触れません。同じ名前のファイルがあれば、名前の後ろに「_2」などを付けて写します。
- ［元のファイルに戻す］を押すと、写したファイルは消えます（元の場所のファイルは、そのままです）。
- 一覧にあるファイル・削除したファイル・「元のファイル」フォルダの中のファイルは、追加できません。
- 削除も追加も、更新するまでは、元に戻す（Ctrl+Z）で取り消せます。

## 3.5 ファイルの更新と、元のファイルに戻す操作

**ファイルを更新**

「ファイルを更新」を押すと、**読み込んだすべてのファイル**が、それぞれの処理の項目のチェックのとおりに更新されます（左のペインで選んでいるファイルだけではありません）。

押すと、まず確認の画面が表示されます。確認の画面には、処理ごとの件数（ファイル名整形○件、メタデータ除去○件、証拠番号スタンプ○件など）と、**内容を変えるファイルのうち、まだプレビューを表示していないファイルの数**が示されます。証拠番号スタンプを付けられるのにチェックの入っていない画像（JPEG・PNG）があるときは、**「証拠番号スタンプを付けない画像：○件」**の行も示されます（画像のスタンプは自動ではチェックが付かないため、付け忘れがないかをここで確かめられます。チェックを外したまま一度更新した画像は、次からは数えられません）。まだ表示していないファイルがあるときは、いったん「キャンセル」を選び、左のペインでそのファイルを選んで、プレビューと処理の項目を確かめてから更新することをお勧めします。「OK」を選ぶと更新が始まります。

個別のファイルの更新に失敗した場合（そのファイルを他のアプリで開いている等）は、エラー内容とともに「この1件をとばして続けるか、残りを中止するか」を選択できます。失敗したファイルは、更新する前のままです。更新できなかったファイルは、完了時のダイアログに、名前と理由が並びます（3.7参照）。

**「元のファイル」フォルダ**

更新する前のファイルは、対象フォルダの中に作られる**「元のファイル」フォルダ**に、そのまま残されます。

- 「元のファイル」フォルダに同じファイルが既にあるときは、保存されません。つまり、同じファイルを2回、3回と更新しても、「元のファイル」フォルダに残るのは、**最初に更新する前のファイル**です。
- 最初の更新の後にフォルダへ足したファイルは、そのファイルを初めて更新するときに保存されます。
- 「元のファイル」フォルダには、ほかに、更新の記録（更新記録.json。どのファイルにどの処理をしたか）が置かれます。**このフォルダの中のファイルは、名前を変えたり動かしたりしないでください**（「元のファイルに戻す」ができなくなります）。
- 「元のファイル」フォルダは、mintsに提出するものではありません。本ツールも、このフォルダの中は読み込みません。

**更新の後**

更新が済むと、フォルダが自動で読み込み直されます。**処理の済んだ項目のチェックは外れます**（メタデータ除去など。済んだ処理は、もう検出されないためです）。

**証拠番号スタンプだけは、扱いが異なります。** 更新の後は、チェックが「スタンプが付いているかどうか」を表します。

- **スタンプを付けたファイルは、チェックの入った状態で表示されます。** チェックを入れたままなら、もう一度更新しても何も起きません（スタンプが二重になることはありません）。
- **チェックを外して「ファイルを更新」を押すと、スタンプが消えます。** チェックを外した時点で、プレビューがスタンプのない状態に切り替わります。スタンプを消すときは、「元のファイル」フォルダに残っている更新する前のファイルから、スタンプ以外の済んだ処理（メタデータ除去など）だけをやり直して作り直します。そのため、**更新の後に他のアプリでそのファイルを直していた場合、その内容は失われます**（更新の確認の画面に「証拠番号スタンプの消去：○件」と表示されます）。
- スタンプのチェックを外して更新したファイルには、読み込み直しても、自動でチェックが付くことはありません（次の更新で、意図せずスタンプが付くのを防ぐためです）。付けたくなったら、チェックを入れて更新してください。
- スタンプを付けたファイルには、位置調整のボタンは表示されません。位置を変えたいときは、いったんチェックを外して更新し、チェックを入れ直して位置を調整してから、もう一度更新してください。

**元のファイルに戻す**

「元のファイルに戻す」を押すと、本ツールで更新したすべてのファイルが、「元のファイル」フォルダに残っている、更新する前のファイルに戻ります。名前を変えたファイル、結合したファイル、「提出用_01」等へ移したファイルも、元の名前・元の位置に戻ります。分割で新しく作ったファイルは、消えます。戻した後はフォルダが読み込み直され、処理の項目のチェックは、再び自動で付きます。

- **更新の後に、他のアプリでそのファイルを直していた場合、その内容は失われます**（更新する前のファイルに置き換わるためです）。押すと確認の画面が出ますので、確かめてから「OK」を選んでください。
- 戻す先に、更新の後で置かれた同じ名前の別のファイルがあるときは、上書きせず、その1件だけを戻さずにお知らせします（更新する前のファイルは「元のファイル」フォルダに残ります）。
- すべてのファイルを戻すと、「元のファイル」フォルダはなくなります。
- このボタンは、対象フォルダに、本ツールで更新したファイルがあるときだけ押せます。

## 3.6 200MBを超える場合の扱い

合計サイズが200MB（既定の安全マージン90％＝180MB）を超える場合、「ファイルを更新」のときに、対象フォルダの直下に「提出用_01」「提出用_02」…という提出回ごとのサブフォルダが自動で作られ、ファイルがそこへ移されます（更新の確認の画面に、その旨と件数が示されます）。1回の提出で収まる場合は、サブフォルダは作られず、ファイルは元の位置のままです。完了時には、何回に分けて提出するかが表示されます。各サブフォルダの中身を、提出回ごとにmintsへアップロードしてください。

内容を変えずに移されるだけのファイルは、「元のファイル」フォルダには写されません（移した元の位置だけが記録され、「元のファイルに戻す」で元の位置に戻ります）。

なお、**単体で200MBを超えるファイル**が検出された場合は、複数回に分けても解決しない重大な警告として、右のペインと更新の確認の画面に表示されます。「画像を軽くする」（3.3節）で小さくするか、ページの位置でファイルを分けて（3.4節「ファイルを分割する」）、1つが200MB以下になるようにしてください。「画像を軽くする」にチェックを入れて、大きさの見込みが200MB以下になったファイルには、この警告は出なくなります。

## 3.7 完了時の確認

更新が済むと、更新した件数を示すダイアログが表示されます。

- **更新できなかったファイルがあるとき**は、その名前と理由（他のアプリで開いている可能性がある、等）が並びます。それらのファイルは、更新する前のままです。原因を取り除いてから、もう一度「ファイルを更新」を押してください（更新が済んだファイルは、チェックが外れているので、二重には処理されません）。
- 複数回に分けて提出する必要があるときは、「提出用_01」等のフォルダごとの件数が表示されます（3.6参照）。
- 証拠説明書のあるフォルダでは、証拠説明書を作り直したことと、そのファイルの名前が表示されます（3.8参照）。
- **「OK」と「フォルダを開く」の2つのボタン**があり、後者を選ぶとダイアログを閉じると同時に、更新したフォルダがエクスプローラーで開きます。

Ver.170まで出力していたレポート（mints提出前レポート.txt）は、Ver.200で廃止しました。検出結果は、ファイルを選んだときの右のペイン（3.3参照）と、画面下部の号証の連番・欠番の表示（3.1参照）で確認できます。どのファイルにどの処理をしたかは、「元のファイル」フォルダの更新の記録に残り、更新する前のファイルも同じフォルダに残ります。

## 3.8 証拠説明書を作る

Ver.310から、mintsに出す**証拠説明書のPDF**を、このツールで作れるようになりました。証拠説明書は、電子証拠説明書と兼ねて作り、PDFで提出します（最高裁判所「民事訴訟フェーズ３に向けた準備の手引」27〜28頁）。書式は、VBAアセットの「証拠説明書」（Wordのテンプレート）と同じです（A4縦、MS明朝。列は「号証・標目・作成年月日・作成者・立証趣旨・備考」）。WordやExcelの文書は作りません。

**証拠説明書を作る**

リボンの「証拠説明書」の組の［作成］を押すと、そのフォルダの証拠説明書（PDFとデータ）を作ります。作った後は、右のペインの、ふだんの項目（処理の項目など）の下に、いつも証拠説明書の入力欄が出ます。左の一覧で証拠を選ぶと、その証拠の行の入力欄が出ます。中央のペインは、選んだ証拠のプレビューのままなので、証拠を見ながら入力できます。［作成］は、まだ証拠説明書を作っていないフォルダでだけ押せます。

**証拠説明書のPDF**

- ［作成］を押したときに、対象フォルダの直下に証拠説明書のPDF（「証拠説明書.pdf」。番号を入れたときは「証拠説明書（2）.pdf」など）を作り、左の一覧の**いちばん上**に出します。
- その後は、入力を変えるたびに、少し待ってからPDFを作り直します（［ファイルを更新］を押さなくても、一覧でPDFを選べば、今の姿をプレビューで確かめられます）。
- 待たずに最新にしたいとき（プレビューに入力がまだ出ていないときなど）は、**F5キー**を押します。入れかけの入力をすぐ保存し、PDFを作り直して、一覧・右のペイン・プレビューを描き直します。
- 左の一覧でPDFを選ぶと、右のペインに、**頭書**（裁判所・事件番号など）の欄と、**全部の行**の入力欄が並びます。頭書は、ここで入れます。
- プレビューで表の行をクリックすると、右のペインが、その行の入力欄まで送られます。1ページ目の表より上（頭書）をクリックすると、右のペインの先頭（頭書の欄）へ送られます。
- mintsでは、証拠と同じアップロードの画面で、ファイル種別のタブを「証拠説明書」に替えて追加し、証拠と一緒に［提出］します（mints操作マニュアル65〜68頁）。
- 合計が200MBを超えて「提出用_01」等に分けるときは、［ファイルを更新］で、証拠説明書を「提出用_01」（最初の回）に入れます。「元のファイルに戻す」で、直下に戻ります。
- 対象フォルダに、たまたま同じ名前（「証拠説明書.pdf」など）の、このツールで作ったのではないファイルがあるときは、上書きしません（画面の下の行でお知らせします）。そのファイルの名前を変えるか、証拠説明書の番号を変えてください。

**行と号証・標目**

- 対象フォルダの中の、**ファイル名の先頭に証拠番号のあるファイル**が、1つにつき1行になります（証拠番号の順に並びます）。証拠番号のないファイル（準備書面など）は、行になりません。
- 枝番の範囲のあるファイル（例：「甲005-1~3 領収書.pdf」）は、**枝番ごとに1行**になります（甲005-1、甲005-2、甲005-3）。
- **号証と標目は、ファイル名から決まります。** 準備の手引29頁は、ファイル名を「証拠番号（半角三桁）に加えて証拠説明書に記載する証拠の標目のとおり記載（英数字は半角）」とするとしているため、証拠説明書とファイル名が食い違わないよう、1つのものとして扱います。
  - 1行のファイルで標目を直すと、ファイル名の標目も変わります（左の一覧の名前に「＊」が付き、［ファイルを更新］で名前が変わります）。このとき、ファイル名は手引の形にそろえます（「甲001 売買契約書」のように、証拠番号と標目の間は半角の空白1つ、英数字は半角）。号証を変えるときは、左の一覧でファイル名を変えてください（3.2節）。
  - 枝番ごとの行の標目は、行ごとに変えられます（ファイル名は変わりません。既定は、ファイル名の標目です）。
  - ファイル名は100文字以内で、使えない文字があるため（3.2節）、1行のファイルの標目も、その範囲で書きます。

**入力欄**

| 欄 | 内容 |
|---|---|
| 標目 | 上のとおり。「標目をまたがせる」にチェックを入れた行は、欄が立証趣旨と同じ高さになります（改行は入れられません） |
| 原本・写しの別 | 準備の手引27頁の4つの類型から選びます（下の表） |
| 作成年月日・作成者 | **もとの資料の**作成年月日・作成者を入れます（電子化した日・人ではありません。準備の手引27頁）。本ツールが推測で入れることはありません |
| 立証趣旨・備考 | 複数行で入れられます |
| 標目をまたがせる | 作成年月日と作成者がともに空の行で、標目を作成年月日・作成者の欄までまたがせて書きます（長い文献名などに） |

頭書（証拠説明書のPDFを選んだときに入れます）：

| 欄 | 内容 |
|---|---|
| 裁判所・事件番号 | 表の上の1行目に出ます（例：東京地方裁判所　令和8年（ワ）第123号） |
| 証拠説明書の番号 | 「証拠説明書（2）」の「2」。PDFの名前にも使います（「証拠説明書（2）.pdf」）。番号を変えると、前に作ったPDFは消して、新しい名前で作り直します |
| 提出の日 | 右寄せで出ます（例：令和8年11月18日） |
| 提出者の別 | 原告・被告など。空のときは、証拠番号の符号から決めます（甲＝原告、乙＝被告） |
| 提出者の名前 | 例：原告訴訟代理人弁護士　甲野太郎 |

| 原本・写しの別 | 証拠説明書への書き方 | ファイル名 |
|---|---|---|
| 原本（期日に原本を持参する書証） | 標目の2行目に「原本」 | 末尾に「原本」が付きます（例：「甲001 売買契約書原本.pdf」） |
| 紙を電子化（電磁的記録として提出） | 備考に「紙を電子化」 | 変わりません |
| 写し（紙の写しを書証として提出） | 標目の2行目に「写し」 | 末尾に「写し」が付きます |
| もともとデータ（電磁的記録として提出） | 何も書きません | 変わりません |

- 読み込んだときに、ファイル名の末尾が「原本」のファイルは、「原本」が選ばれた状態になります。末尾の「写し」は、標目の一部のこともある（「住民票の写し」など）ため、自動では選びません。「写し」を選んだとき、標目が既に「写し」で終わっていれば、名前は変えずに、その「写し」を2行目に移します。
- 表の上に「※「標目」欄に原本・写しの記載がないものは、民事訴訟法２３１条の２の電磁的記録として提出するものである。」と書きます。

**データの保存**

入力は、その場で、対象フォルダの中の「**証拠説明書データ**」フォルダの `証拠説明書.json` に保存されます（証拠のファイルは変わらないので、確認は出ません）。次に同じフォルダを読み込むと、入力が戻ります。ファイルの名前を変えたり、枝番ファイルを結合したり、「元のファイルに戻す」で戻したりしても、行はそのファイルに付いていきます。「証拠説明書データ」フォルダは、読み込みの対象になりません（mintsにも送りません）。

**［ファイルを更新］のとき**

- 標目の直しなどのファイル名の変更は、［ファイルを更新］を押すまで下書きです。その間、証拠説明書のPDFの号証・標目は、まだ変えていない実際のファイル名より先に進んでいることがあります。［ファイルを更新］のときにもPDFを作り直してそろえるので、**mintsに出すのは、［ファイルを更新］をした後の証拠説明書のPDF**にしてください。
- 確認の画面に「証拠説明書の作成：1 件」と、原本・写しの別を選んでいない行の数、作成年月日・作成者・立証趣旨のどれかが空の行の数が示されます（作るのを止めはしません）。
- 更新できなかったファイルがあったときは、号証・標目がファイルとそろわないおそれがあるため、証拠説明書は作り直しません（完了のお知らせに、その旨が出ます）。原因を取り除いてから、もう一度［ファイルを更新］を押してください。
- 見出しの行は、各ページに出ます。行の途中では改ページしません（1つの行が1ページに収まらないときだけ、ページごとに分けます）。
- 範囲を選んで一部の証拠だけの証拠説明書を作ることはできません。対象フォルダの中の、証拠番号のあるファイルすべてが入ります。後から証拠を足して「証拠説明書（2）」を出すときは、提出のたびに対象フォルダを分けてください。

**証拠説明書を消す**

左の一覧で証拠説明書のPDFを選んで［削除］（Deleteキー、または右クリックの［一覧から削除］）を押すと、確認のうえ、証拠説明書のPDFとデータ（「証拠説明書データ」フォルダ）を、その場でごみ箱に移します（ごみ箱から戻せます）。ほかのファイルの削除と違い、下書きにはせず、「元のファイルに戻す」の対象にもなりません。消した後は、もう一度［作成］を押すまで、証拠説明書は作りません（［作成］が、また押せるようになります）。証拠説明書と、ほかのファイルを一緒に選んで削除することはできません。

## 3.9 ヘルプメニューと診断情報

画面上部のメニューは、［ファイル］（3.1参照）と［ヘルプ］の2つです。［ヘルプ］メニューから、次の操作ができます。

- **診断情報をコピー**：ツールの版・OS・設定の数値・読み込んだ件数・起きたエラーの型と場所（ファイル名・行・関数名）だけをまとめた文を、クリップボードにコピーします。**証拠・書面のファイル名、ファイルやフォルダの場所、エラーメッセージの本文など、事件の内容につながる情報は含まれません。** 不具合をAIや作成者に相談するときは、この診断情報を使ってください（中身は入りません）。渡す前に、メモ帳などに貼り付けて内容を確かめることもできます。
- **VA mints について**：ツールの名前と版を表示します。

# 第4章 設定ファイル（config.yaml）

`config.yaml` では、数値パラメータ等をハードコードせず一元管理しています。テキストエディタで開いて編集できます。主な項目は次のとおりです。

| セクション | 主な項目 | 内容 |
|---|---|---|
| `upload` | `max_total_mb`、`safety_margin_ratio` | 1回のアップロード合計上限（既定200MB）と分割時の安全マージン（既定90％） |
| `evidence_number` | `symbols`、`digits` | 証拠番号の符号（甲・乙・丙）と桁数 |
| `filename` | `max_length`、`warning_length`、`forbidden_chars` | ファイル名の上限文字数（既定100）・警告閾値（既定50）・禁止文字 |
| `evidence_stamp` | `font_size_pt`、`margin_top_mm`、`margin_right_mm`、`style` | 証拠番号スタンプの文字サイズ（既定16ポイント）・余白・見た目（既定は赤字）。［ファイル］→［オプション］で変えた大きさ・見た目があれば、そちらが使われます |
| `pdf` | `a4_mm`、`a3_mm`、`size_tolerance_mm` | 用紙寸法と判定の許容誤差（用紙をA4にそろえるときも、この寸法を使います） |
| `compress` | `auto_lossless_mb`、`reduce_dpi`、`jpeg_quality` | 「画質を損なわない圧縮」に自動でチェックを付ける大きさ（既定10MB）、「画像を軽くする」で選べる解像度（既定300dpi・200dpi・150dpi。先頭が既定）、JPEGにするときの画質（既定80）。このセクションがない古い設定ファイルでも、既定の値で動きます |
| `pii_detection` | `patterns` | 個人情報パターン検出の正規表現（追加・調整可能） |
| `logging` | `log_dir`、`level` | デバッグ用詳細ログの出力先とレベル |

各項目には、根拠とした一次資料（操作マニュアルの版数、準備の手引の版数等）がコメントとして記載されています。数値の意味や根拠を確認したい場合は、`config.yaml` 内のコメントを直接ご参照ください。

編集内容に誤りがある場合（正規表現の書き間違い、必要な項目の削除等）は、起動時にどこをどう直すべきかを示すエラーダイアログが表示されます。その場合は、メッセージに従って該当箇所を修正するか、配布時の `config.yaml` の内容に戻してください。

# 第6章 AIを使ってツールを改造するとき

本ツールはソースコードを同梱しており、事務所独自の機能をAI（コーディング支援のAI）で追加することもできます。その場合は、次の手順で、**AIが実データ（依頼者・事件の情報）に届かない場所で作業させてください。**

## 6.1 なぜ注意が必要か

AIが読んだファイルや画面は、AIの会社のサーバーに送られます。依頼者の情報をAIに読ませると、守秘義務の点で問題になり得ます。AIは作業の途中で、思わぬファイルを開くことがあります。そのため、「気をつけて使う」だけでは防げません。AIが実データに届かない場所で作業させてください。

## 6.2 手順1　AI専用のWindowsユーザーを作る

- ［設定］→［アカウント］→［他のユーザー］で、AIの作業に使うユーザーを作ります。管理者にはせず、標準ユーザーにします。
- このユーザーでは、事務所のOneDrive・SharePointにサインインしません。共有フォルダ・ネットワークドライブ・暗号化した仮想ドライブにもつなぎません。
- 作ったら、このユーザーでエクスプローラーを開き、事務所の共有データの場所が見えないこと、開けないことを確かめます。見える場合は、そのフォルダのアクセス許可からこのユーザーを外してください。
- 別のPCをAIの作業に使えるなら、さらに確実です。

## 6.3 手順2　このユーザーで、ソースと試用データだけを使って作業する

- ソースと試すデータは、このユーザーで新しく手に入れます。サイトから配布物（zip）をダウンロードし直し、`source/` フォルダのソースコードを使います（GitHubのVBA-Assets/VA_MINTSから取ってもかまいません）。ふだんのユーザーのフォルダから写さないでください。
- 設定ファイル（`config.yaml`）も、新しくダウンロードした配布物のものを使います。ふだん使っているものを写さないでください。
- 試すデータは、架空の文書か、付属のスクリプト（`source/scripts/generate_sample_folder.py`）で作る架空のサンプルファイルを使います。実際の証拠・書面は使いません。
- 実データの中身を、AIに貼り付けたり、画面の写しで見せたりしないでください。
- 不具合をAIに相談するときは、［ヘルプ］→［診断情報をコピー］（3.9参照）を使います。診断情報には、版・設定の数値・件数やエラーの場所だけが入り、ファイル名などの中身は入りません。

## 6.4 手順3　実データでの確認と入れ替えは、ふだんのユーザーで人が行う

- 改造してできた実行ファイル（`config.yaml` を変えた場合はそれも）を、ふだんのユーザーに移します。
- まず実データの写しを置いた試験用のフォルダで試し、問題がなければ使い始めます（本ツールは対象フォルダの原本を書き換えませんが、念のため写しで試してください）。
