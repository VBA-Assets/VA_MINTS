# サンプルフォルダ（手動テスト用）

`scripts/generate_sample_folder.py` が生成した合成データです。実際の証拠・準備書面等の内容は一切含みません。GUIの「フォルダを読み込み」を試す際の入力フォルダとして使用できます。

再生成する場合：

```
.venv\Scripts\python.exe scripts\generate_sample_folder.py
```

## 新機能（2026-07-20〜21追加分）の確認方法

上記のうち「号証の連番・欠番チェック」の2件は、**スキャン結果一覧やチェックボックスには表れず**、実際に「ファイルを書き出し」を実行した後に出力フォルダへ生成される `mints提出前レポート.txt` の【号証の連番・欠番チェック】欄でのみ確認できる（検出・警告のみで自動実行されるため、書き出し前の確認ダイアログは出ない）。

「スタンプ位置調整UI」は専用のサンプルファイルを設けていない。証拠番号の付いたファイル（甲001・甲008・甲009・甲011等）を書き出す際の逐次レビュー画面で、証拠番号スタンプのチェックボックスをONにすると、プレビュー右側に位置調整ボタン（上下左右・リセット）が表示される。
