# サンプルフォルダ（手動テスト用）

`scripts/generate_sample_folder.py` が生成した合成データです。実際の証拠・準備書面等の内容は一切含みません。画面の［ファイルを読み込み］を試すときの対象フォルダとして使えます。［ファイルを更新］を試すときは、このフォルダを写してから、写しの方で試してください（更新すると、ファイルが書き換わります）。

再生成する場合：

```
.venv\Scripts\python.exe scripts\generate_sample_folder.py
```

## 確かめ方の補足（Ver311 で、いまの画面に合わせて直した）

「号証の連番・欠番チェック」の2件は、左の一覧や右のペインの項目には表れず、読み込んだ後の画面の下部にだけ表示される（検出・お知らせのみ）。

証拠番号スタンプの位置と見た目は、証拠番号の付いたファイル（甲001・甲008・甲011 など）を選び、右のペインの［証拠番号スタンプ］にチェックを付けて、中央のプレビューで確かめる。文字の大きさと見た目（黒字・赤字・赤字に赤枠）は［ファイル］→［オプション…］で変えられる。
