# VA mints

mints（民事裁判書類電子提出システム）の「記録」に出す前のファイルを、フォルダごとまとめて確かめ、提出用 PDF の準備までを行うツールです。

- ファイル名・用紙の大きさ・パスワード・メタデータ・200MB の上限などを確かめ、要るものに処理のチェックを付けます。
- ページの削除・挿入・並べ替え・回転、ファイルの結合・分割、ファイル名と証拠番号、証拠番号のスタンプ、圧縮、A4 へのそろえ、付箋・コメントの除去を、プレビューで確かめてから行います。
- 証拠説明書（mints に出す PDF）を、このツールの中で作れます。
- 更新する前のファイルは、対象フォルダの中の「元のファイル」フォルダに残り、［元のファイルに戻す］で戻せます。
- 外部と通信しません。

## 使い方

`VA_mints.exe` をダブルクリックします。`config.yaml`（mints の上限などの数値）は、exe と同じフォルダに置いてください。詳しくは、`マニュアル\` の操作マニュアルをご覧ください。

## ソースから動かす（Windows・Mac）

```
pip install -r requirements.txt
python main.py
```

試験：`python -m pytest`

Mac では、ソースから動かせます（動作は保証しません）。
